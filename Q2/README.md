## Gadget Galaxy

Gadget Galaxy is a small online store that sells smart, everyday gadgets like earbuds, power banks, USB cables, phone stands and mice.
The one-page storefront shows products in a styled table and includes categories, a subscribe form and quick links.

## Part 11

The tagline is green because the inline style beats everything else.
All the other p tags are dark red because my internal CSS overrides the grey in store.css.
This happens because the browser follows inline > internal > external, and inline has the highest specificity.
